# Sarawak Crafts - Project Specification

## 1. Project Overview
Sarawak Crafts is a proposed e-commerce website
for showcasing and selling Sarawak handicrafts.

## 2. Project Objectives
- Promote Sarawak handicrafts and local culture.
- Provide a user-friendly online shopping experience.
- Support product browsing and order management.

## 3. Proposed Technology Stack
- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
- Local Server: XAMPP
- Version Control: Git and GitHub

## 4. Proposed System Modules
- User Authentication
- Product Catalog
- Shopping Cart
- Checkout
- Admin Dashboard
- Database Management

## 5. Folder Structure
- config/ - System and database configuration
- includes/ - Reusable PHP components
- assets/ - CSS, JavaScript and images
- catalog/ - Product catalog
- auth/ - Login and registration
- cart/ - Shopping cart
- checkout/ - Checkout process
- admin/ - Administration modules
- database/ - Database scripts

## 6. Development Guidelines
- Use GitHub for version control.
- Develop features in separate branches.
- Use meaningful commit messages.
- Review changes before merging into main.
